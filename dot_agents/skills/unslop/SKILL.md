# Unslop

Read the pattern catalog at `~/.agents/unslop.md` at the start of each
conversation. Before sending any reply or saving any prose, scan it for every
applicable pattern and rewrite until none remain. Apply this throughout the task,
including when another skill is in use. Preserve meaning, technical accuracy,
required syntax, and the intended tone.
